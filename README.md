# SumIT Reader

קורא את הסיכומים האינטראקטיביים של SumIT בטלפון ובטאבלט. אתר סטטי שמתקינים למסך הבית; הסיכומים נשמרים על המכשיר ופועלים גם בלי אינטרנט.

## שימוש
1. ב-SumIT במחשב: שיתוף בהרצאה, ושמירת ה-ZIP ב-OneDrive.
2. בטלפון או בטאבלט: פתיחת הקורא, בחירת ה-ZIP מ-OneDrive.

## פיתוח
אין תהליך בנייה. להרצה מקומית: python -m http.server בתיקייה ופתיחת http://localhost:8000 (נדרש localhost או https בגלל Service Worker). פענוח ZIP עם fflate (MIT).
